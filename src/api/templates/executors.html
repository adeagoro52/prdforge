Executor Selection

The executor for a task is selected using this priority:

  1. Task-level - Explicit executor in task configuration
  2. Project-level - Default executor in project settings
  3. Global default - claude-cli is the default executor

To use a different executor, configure API keys for the desired backend and select it in your project settings or specify it per-task in your PRD.
