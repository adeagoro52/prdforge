Skill Override System

Skills can be overridden using a hierarchical system:

  1. Package (built-in) - Base skills provided by PRDForge
  2. User - Personal skills in ~/.prdforge/skills/ override package skills
  3. Project - Project skills in .prdforge/skills/ override both

To override a skill, create a skill with the same name in a higher-priority location. For example, to customize the "lint" skill for a specific project, create .prdforge/skills/lint.yaml in your project.
